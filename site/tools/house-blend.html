How we pick them

The café chooses a handful of everyday jobs, then the best-known tool on the menu for each one, preferring tools published by the company behind the service. If a tool leaves the menu, the next one in line takes its place. Some of these services need an account, and some have paid plans; check with the service itself.

“Popular” is not a security review. Read what a tool can do before you connect it, and only connect tools you trust: a connected tool can act on your behalf.

What is an MCP tool?

An MCP server is a small connector that lets your AI agent act on a service, like opening a pull request or updating a Notion page, instead of only talking about it. Each tool on the menu has copy-paste setup steps for Claude Code, the Claude app, ChatGPT, Codex, Gemini CLI, GitHub Copilot and Cursor.
