advisor

OfficialPlanning & WorkflowMade for ClaudeBuilt into Claude Code

Lets Claude ask a second, stronger AI model for advice during long or tricky tasks.

Comes with Claude Code, by Anthropic. Nothing to download or install. Official documentation ↗

See it on the menu →

When to reach for it

Long, multi-step work where a second opinion saves time: big refactors, a bug that keeps coming back, or checking a plan before Claude commits to it. It adds little on short tasks.

How to use it

  1. Open Claude Code: in a terminal, the desktop app or Remote Control.
  2. Type this, then pick a model from the list:
    /advisor
  3. Or name the model straight away (opus, sonnet or fable):
    /advisor opus
  4. Work as usual. Claude asks the advisor on its own when a second opinion helps.
  5. To stop using it:
    /advisor off

The advisor should be as strong as or stronger than the model doing the work — for example Sonnet working with Opus advising.

Advisor use counts toward your Claude plan’s usage limits, or is billed at the advisor model’s rates if you use an API key.

Works when Claude Code connects through Anthropic’s own plans or API (also Claude on AWS and Google Cloud); not through Amazon Bedrock or Microsoft Foundry.
