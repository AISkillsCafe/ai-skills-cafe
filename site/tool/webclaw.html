What is an MCP tool?

An MCP server is a small connector that lets your AI agent act on a service, like reading or updating things in webclaw, instead of only talking about it.

How to connect it

Runs online: your agent connects to https://api.webclaw.io/mcp, so there’s nothing to install.

The menu has copy-paste setup steps for Claude Code, the Claude app, ChatGPT, Codex, Gemini CLI, GitHub Copilot, Cursor and other agents.

Only connect tools you trust: a connected tool can act on your behalf.
