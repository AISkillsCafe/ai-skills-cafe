What is an MCP tool?

An MCP server is a small connector that lets your AI agent act on a service, like reading or updating things in Terraform, instead of only talking about it.

How to connect it

Runs on your computer using Docker (docker.io/hashicorp/terraform-mcp-server:1.4.1).

The menu has copy-paste setup steps for Claude Code, the Claude app, ChatGPT, Codex, Gemini CLI, GitHub Copilot, Cursor and other agents.
