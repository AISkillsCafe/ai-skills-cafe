What is an MCP tool?

An MCP server is a small connector that lets your AI agent act on a service, like reading or updating things in Figma MCP Server, instead of only talking about it.

How to connect it

Runs online: your agent connects to https://mcp.figma.com/mcp, so there’s nothing to install.

The menu has copy-paste setup steps for Claude Code, the Claude app, ChatGPT, Codex, Gemini CLI, GitHub Copilot, Cursor and other agents.
