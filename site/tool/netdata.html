What is an MCP tool?

An MCP server is a small connector that lets your AI agent act on a service, like reading or updating things in Netdata, instead of only talking about it.

How to connect it

Runs online: your agent connects to https://app.netdata.cloud/api/v1/mcp, so there’s nothing to install.

It needs an access key or token from the service. The menu explains where to get one.

The menu has copy-paste setup steps for Claude Code, the Claude app, ChatGPT, Codex, Gemini CLI, GitHub Copilot, Cursor and other agents.

Only connect tools you trust: a connected tool can act on your behalf.
