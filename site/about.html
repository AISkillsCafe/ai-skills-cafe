How the café works

AI Skills Café helps you find good skills and tools for your AI agent. A skill is a folder of instructions your agent follows (the open SKILL.md format). A tool is an MCP server: a small connector that lets your agent act on a service like Notion, GitHub or a database.

For each one we show how to set it up in Claude, ChatGPT, Codex, Gemini CLI, GitHub Copilot, Cursor and other agents. It’s free for everyone, with no sign-up, and the menu refreshes automatically every night.

How we choose

How each label is earned, for skills and for tools

TrustedHand-picked by the café: widely used community collections.Not used for tools.
PopularFound on GitHub with 2,000+ stars, an open-source licence and activity in the last year.Community tools whose own GitHub repository has 300+ stars.

Star counts belong to the source repository, not to a single skill. Being listed is not an endorsement or a security review — please read what a skill or tool does before using it, and only connect tools you trust.

On the Tools menu, House Blend is a short, curated list of well-known tools for everyday jobs, selected by the café. It’s intended as a starting point, not a ranking or a security review.

Credit and licences

Every skill and tool belongs to its author. We show the author, link to the original source and display its licence.

The café only lists skills whose author has clearly chosen an open licence (MIT, Apache 2.0, BSD, ISC, CC BY, GPL and similar), either in the skill itself, in a licence file in its folder, or for its whole GitHub repository. You can read the instructions here and download a copy; both come straight from the author’s GitHub repository, with the licence kept.

Skills with no licence stated, non-commercial or source-available terms (meaning you can read them but not freely reuse them), or unclear terms are left off the menu, even when they’re popular.

Your privacy

There are no accounts, cookies or tracking. The visitor count in the footer goes up by one the first time a browser opens the café; nothing about you is recorded. Your shelf, ratings and notes are saved only in your own browser and never sent to us. Clearing your browser data removes them.

For authors: removal or corrections

If you made a skill or tool listed here and would like it removed or corrected, open a removal request on GitHub ↗. It’s a short form; you’ll need a free GitHub account, and requests are public, so please don’t include private details.

Prefer not to use GitHub? Email removals@aiskillscafe.com with the skill or tool’s name. Email requests stay private.

Requests are handled within 7 days, and removed items stay off the menu.
