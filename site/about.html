A free menu of AI skills and tools

AI Skills Café helps people find good skills (folders of instructions an AI agent follows, in the open SKILL.md format) and tools (MCP servers that let an agent act on a service like Notion, GitHub or a database), and shows how to set each one up in Claude, ChatGPT, Codex, Gemini CLI, GitHub Copilot, Cursor and other agents.

It’s free for everyone, with no sign-up. The menu refreshes automatically every night.

Star counts belong to the source repository, not to a single skill. Being listed is not an endorsement or a security review — please read what a skill or tool does before using it, and only connect tools you trust.

Credit and licences

Every skill and tool belongs to its author. We show the author, link to the original source and display its licence.

  • Openly licensed skills (MIT, Apache 2.0, BSD, ISC, CC BY, GPL and similar): you can read the instructions here and download a copy. Both come straight from the author’s GitHub repository, with the licence kept.
  • Everything else (no licence stated, non-commercial, source-available or unclear terms): we show only a short description and send you to the author’s own page.

Your privacy

There are no accounts, cookies or analytics. Your shelf, ratings and notes are saved only in your own browser and never sent to us. Clearing your browser data removes them.

For authors: removal or corrections

If you’d like your skill or tool removed, or something about it corrected, send a removal request and it will be handled promptly. Removed items stay off the menu.
